# AI CLASS Website

Modern AI education website with courses, benefits, pricing, responsive design, and a Login / Create Account front-end panel.

## GitHub
https://github.com/Brokencat005/framecut-video-editing-website/tree/main/ai-class

## Firebase
Configured for Firebase project `framecut-video-editing`. From the `ai-class` folder, run `firebase login` and then `firebase deploy` to publish it to Firebase Hosting.

The Login panel is a front-end demo. For real accounts, enable Firebase Authentication and connect the login forms to it.
